# 🍵 월하다원 (月下茶園) — 오늘의 사주·띠·별자리·타로 다실

전통 한지 감성의 종합 운세(생년월일 60갑자 사주·12띠·12별자리·수묵 메이저 아르카나 22장 타로·1:1 차담) 웹앱입니다.

## 주요 기능
- **생년월일 명패 자동 분석**: 60갑자 연주·오행·12띠·황도 12궁 별자리 및 오늘 일진(日辰) 자동 계산
- **Gemini AI 실시간 종합 풀이**: `gemini-3.8-flash` / `gemini-4-argon` 연동 구조화 운세 및 개운 처방전
- **수묵 타로 다실**: 원카드(1장) · 쓰리카드(3장) 3D 카드 뒤집기 및 AI 리딩
- **다실 미리보기 지원**: API 키 입력 전에도 모든 기능을 샘플로 즉시 체험 가능
