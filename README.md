# 🌈 무지개 피아노 교실 — 우리 아이 동요 피아노 웹앱

아이들이 반짝이는 별빛 가이드를 따라 동요를 쉽고 재미있게 연주할 수 있는 피아노 연습 웹앱입니다.

## 주요 기능
- **🎵 인기 동요 8곡 내장**: 작은 별, 나비야, 비행기, 학교종이 땡땡땡, 곰 세 마리, 산토끼, 생일 축하 노래, 징글벨
- **✨ 불빛 따라 치기 모드**: 다음에 눌러야 할 건반에 `👇 도!` 풍선과 황금빛 불빛이 반짝이며, 완주 시 폭죽과 함께 칭찬 별 스티커 지급
- **🎧 자동 연주 듣기**: 느리게(🐢) / 보통(🐰) / 빠르게(🚀) 속도로 시범 연주 감상
- **🎹 4가지 악기 소리 & 녹음기**: 피아노, 실로폰·오르골, 아코디언, 우주 신스 음색 및 내 연주 녹음·다시 듣기
